# WUN 0.1.0-beta.3

Personal queues and unique supports, enriched notifications and administrator decisions, native configuration/metrics, automatic availability reconciliation and optional retention. Tested on Jellyfin 12.4.0 / Linux x64. All deletion and expiration policies are disabled by default.

- Separate personal requests from the administrator general queue; preserve unique interest counts and original ownership of new records.
- Show request covers, scope, participants to administrators and richer notification context without exposing private notes to regular users.
- Reopen declined/canceled requests only after confirmation. Complete requests when the requested catalog scope is available; ongoing series remain monitored.
- Configure request rules, limits and retention through the native dashboard. Preview cleanup, run native tasks and inspect their results.
- Organize configuration into Overview, Requests, and Cleanup and tasks, with explicit policy enable controls and preserved unsaved values across tabs.

## Upgrade and recovery

The WUN database migrates from schema 1/2 to schema 3. Back up plugin binaries, plugin configuration and the complete WUN data directory before upgrading. Legacy author/date fields remain unknown. Restore matching binaries and database together to revert; an old DLL cannot open schema 3. Acquisition remains manual. Scheduled review reminders, other server versions/architectures and sustained concurrency are not validated. Requires Plugin Pages and File Transformation 3.0.3.0 Release-12.4.0 for the user-facing page; native administration does not depend on them.
