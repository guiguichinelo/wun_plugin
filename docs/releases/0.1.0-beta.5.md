# WUN 0.1.0-beta.5

Reduce repeated work in request queues, notifications, searches and title details. Cache public provider data with bounded retention and shared in-flight loads; keep workflow decisions, supports and read state live. Preserve list controls and cards while refreshing.

- Cache provider searches and resolved metadata for 15 minutes and artwork URLs for 30 minutes, keyed by operation, media type, identifiers, language and country. Existing schedule data retains its 15-minute limit and now includes country in its key.
- Coalesce identical in-flight loads. Canceling one client only cancels that client's wait; shared provider loads have a 30-second cancellation deadline. Provider concurrency remains limited.
- Retain bounded cache entries without flushing the entire collection at capacity. Failed/missing metadata is retried rather than retained as a successful result.
- Cache local catalog/coverage observations for at most 10 seconds, separated by user and current policy. Library add/update/remove events invalidate observations. Native visibility checks and administrator policies remain in force; background availability maintenance bypasses the interactive coverage cache.
- Present the same request once per notification response, even when it has several events. Never cache decisions, participation, requester data or notification read state between HTTP requests. API responses remain private/no-store.
- Keep filters and existing cards visible while a refresh is pending, with an accessible busy state. Preserve page-generation and account-change guards.

Validated against Jellyfin 12.4.0, Linux x64. Automated checks cover cache expiration, locale separation, failed loads, cancellation, shared loads, library/policy changes, notification freshness, native authorization boundaries and delayed refresh behavior. Browser checks cover native themes, supported interface locales and mobile layout. No database migration: WUN schema remains 3. Acquisition remains manual; sustained concurrent capacity and other server versions/platforms are not certified. Back up binaries, configuration and WUN data before updating. Install through the Jellyfin 12 Betterfin repository; restart Jellyfin and reload existing web clients to activate the new assembly and script.
