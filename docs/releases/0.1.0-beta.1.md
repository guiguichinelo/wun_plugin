# WUN beta 1

First public beta: catalog search, user requests, administrator decisions, private notes, followers and notifications. Movie/series details, season covers, episode stills, availability and provider release dates. Acquisition is manual; automated monitoring workers are not included.

Jellyfin 12.4.0 / Linux x64 only. Requires Plugin Pages and File Transformation 3.0.3.0 Release-12.4.0. Partial translations use English fallback. Back up configuration and plugin data before installing. Other platforms, native clients and production load remain unvalidated.
