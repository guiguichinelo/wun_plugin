# WUN 0.1.0-beta.9

Open the administrator queue with Awaiting approval selected. Display its filters before waiting for request cards, so users can refine the queue immediately. Keep filter controls and focus stable during refreshes, and ignore responses superseded by a newer filter choice. Personal Following retains its all-states default; other administrator states remain available.

Prepare up to four request cards concurrently per list request, preserving result order and visibility checks. Deduplicate presentation tasks safely within the request. Cancellation stops queued work; provider concurrency limits remain in place. Workflow state and authorization are not cached across requests.

Includes regression coverage for immediate controls with delayed responses, administrator/user defaults, stale responses, bounded concurrency, ordering, denied metadata, filtering before enrichment and cancellation. Retains beta 8's native search shortcuts.

No database migration from beta 8 and no change to retention defaults. Back up plugin binaries, configuration and WUN data before installing. Targets Jellyfin 12.4.0 on Linux x64; Plugin Pages and File Transformation 3.0.3.0 Release-12.4.0 remain required. Other clients, versions and architectures require separate validation. External metadata providers can still affect response times; this release does not promise a fixed loading time.
