# WUN 0.1.0-beta.6

Reconcile requests automatically when catalog items arrive, when a library scan completes and after administrator decisions. Group episode requests by series and season, show availability clearly and open the requested episode directly.

- Coalesce catalog events with a 20-second quiet period and a two-minute maximum wait. Retain pending work after failures and wait for library scans to finish.
- Keep availability reconciliation separate from expiration and cleanup. Preserve rejected, canceled and completed requests; do not reopen completed requests when files become unavailable.
- Recognize multi-episode files, exclude virtual entries and keep whole-series coverage rules. Unknown coverage does not imply completeness.
- Refresh visible request lists every 30 seconds while retaining filters and pagination. Pause refresh during dialogs, focused controls, hidden pages and pending requests.
- Present independent episode decisions, interests and history within each season group. Correct singular/plural labels and default to all request statuses.

Validated on Jellyfin 12.4.0, Linux x64: 66 API tests, 29 core checks, browser fixtures and live catalog/approval/restart checks. No schema migration; WUN schema remains 3. Back up plugin binaries, configuration and data before updating. Restart Jellyfin and reload existing web clients after installation. Sustained capacity, every host version and every library-policy combination are not certified.
