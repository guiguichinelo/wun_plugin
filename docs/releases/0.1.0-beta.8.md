# WUN 0.1.0-beta.8

Offer a request shortcut after native Jellyfin searches, both when no results are found and at the end of matching results. Opening it preserves the search text, resets filters to All and performs one WUN search. Requests still require an explicit user action.

Based on beta 6, with no database migration or additional backend features. Keeps the existing request workflow, catalog reconciliation and disabled-by-default retention policies.

The shortcut follows the native interface styles, uses Portuguese/English with English fallback, and does not query the metadata provider before the user opens it. Correctly encodes search text and prevents a previous form from overwriting a new incoming search.

Validated on Jellyfin 12.4.0 / Linux x64. Native search integration targets the Jellyfin web DOM and requires Plugin Pages and File Transformation 3.0.3.0 Release-12.4.0. Other clients and future DOM changes need separate validation. Back up plugin binaries, configuration and WUN data before updating.
