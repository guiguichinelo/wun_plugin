# WUN 0.1.0-beta.4

Improve request navigation and administrator workflow: correct page titles, separate unread/read notifications, full-row media-type selection, keep search after requesting, default the administrator queue to pending approval, reflect saved decisions in available actions and refresh without losing filters.

- Keep native browser titles scoped to the Requests route.
- Filter notification read state before pagination; marking a notification read moves it out of the unread view without deleting it.
- Fix the focus loss that closed the type picker before a text/row click completed.
- Keep query, type and results after creating requests; protect the interface from stale responses after navigation/account changes.
- Group administrator controls by current state; pending-only queues remove approved requests after saving. Refresh retains current filters, order and page.

Tested on Jellyfin 12.4.0 / Linux x64. No new schema migration beyond schema 3. All retention/expiration defaults remain disabled. The optional read filter preserves the previous API behavior when omitted. Back up plugin binaries, configuration and WUN data before upgrading. User-facing pages require Plugin Pages and File Transformation 3.0.3.0 Release-12.4.0. Acquisition remains manual; other platforms and sustained concurrent load are not validated.
